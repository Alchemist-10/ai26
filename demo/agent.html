Demo build. No LLM runs here. This is a hardcoded tool-call simulator illustrating a possible extension: a local model with a fixed, allowlisted, read-only tool list. Every response below shows which tool it "called" and with what arguments.

Sakshi Agent

Unlike the camera-wall search (scoped to cameras you select), this agent can reach across the whole allowlisted tool surface — trajectories, alerts, congestion, camera events, OD flows — the same way the real NL-query layer would, just with canned answers instead of a live model and database.

Allowlisted tools (mocked)

ToolPurpose
find_trajectory(plate)Chronological cross-camera path for one plate
get_alerts(type?, plate?)Blacklist / impossible-travel / loitering / restricted-zone alerts
get_congestion(segment)Current count vs. weekday/hour baseline, z-score
list_camera_events(camera_id, window)Recent observations at one camera
get_od_flows()Top origin–destination routes

Potential extension: validated arguments, a read-only database role, result limits, and a query log; these are not implemented here. Anything off this list gets refused, not guessed.
